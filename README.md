A fully deployed shopping app to learn and understand development concepts and full stack coding.

Live url: https://mern-shopping-app-eta.vercel.app/

The shopping app contains:
- A login page/register page
- Admin login
   1. Add, delete and modify products in the shop.
   2. Admin dashboard. 
   3. Can check all orders by all customers, update the order status.
-User login
  1. View all shop items, add items to cart, add items to wishlist
  2. Cart- add items, remove items, proceed to checkout
  3. Enter address details and place orders.

**MERN Stack:**
- **MongoDB** - Database
- **Express.js** - Backend framework
- **React** - Frontend library
- **Node.js** - Runtime environment
